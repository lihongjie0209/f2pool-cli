f2pool API supports HTTPS requests to access the mining pool service, which includes support for subaccount management, wallet management, payment information, hashrate, workers and other query functions.

How to get the API token

You can activate the API service and get the API token through the website, or contact f2pool customer service agents.

API authentication

F2P-API-secret
Fill the header with API token on the right field to pass verification. Note that we only accept POST requests with application/json

For example

curl --request POST {url}
--header 'Content-Type: application/json'
--header 'F2P-API-SECRET: {token}'
--data-raw '{
"currency": "bitcoin",
"user_name": "xxx",
...
}'

{url} is https://api.f2pool.com/v2/{request_name} You will get the following uniform formatted data if there is a error

{
"code": {ERR_CODE},
"msg": "error_type: description"
}

The available values of the 'currency' field in the API:

bitcoin,bitcoin-cash,conflux,dash,decred,digibyte-qubit,digibyte-scrypt,digibyte-sha256d,digibyte-skein,dogecoin,elacoin,ethereum,ethereum-classic,handshake,hathor,kadena,litecoin,nervos,nmccoin,qitmeer-meer,raven,siacoin-new,verge-blake2s,verge-groestl,verge-lyra,verge-scrypt,verge-x17,xaya,zcash,zen

The hashrate module currently supports only:

bitcoin,bitcoin-cash,litecoin

The hashrate distribution module currently supports only:

bitcoin

Distribute revenue to a wallet address

Currently supports BTC only and is available only to subaccounts of approved main accounts (not the main accounts themselves). The server creates or reuses an internal recipient and only returns the real wallet address. The API token must explicitly include revenue/distribution/add/to_address; each distributor can create up to 100 new addresses per day.

POST /v2/revenue/distribution/add/to_address

Request Parameter

Name Type Mark description
currency string Currency type. Currently only bitcoin is supported
distributor string The distributor account name
address string The recipient wallet address
description string Description, up to 64 characters
proportion double Proportion in (0, 100], with at most two decimal places

Response Parameter

Name Type Mark description
id string Revenue distribution record id, usable by the delete endpoint
currency string Currency type
distributor string The distributor account name
address string The recipient wallet address
description string Description
proportion double Proportion
proxy_reused bool Whether the internal recipient created for this address was reused
