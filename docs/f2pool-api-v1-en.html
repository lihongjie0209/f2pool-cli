Overview

Users can obtain account hash rate, revenue, and payment status through the API v1 interface provided by f2pool.

This document provides a detailed description of the f2pool API v1 interface calls and return data. Necessary data for mining is described in this document with corresponding calling methods and field explanations. If fields not described in this document appear in the API return values, these fields are reserved or deprecated and should be ignored.

 

Authentication

To query the API, you need to provide a token with legacy/api_v1 permission for the sub-account to get results normally. Users can obtain this token through the API function in the f2pool account settings (make sure to check the legacy/api_v1 permission when requesting the token).

When requesting the API, put the token obtained earlier in the F2P-API-SECRET attribute of the HTTP request header to complete the authentication.

For example:

curl --request GET {url} \
     --header 'Content-Type: application/json' \
     --header 'F2P-API-SECRET: {token}'

Common URLs

Description

https://api.f2pool.com/{currency}/{user}

Retrieves the account details of a specific currency, including mining revenue, account balance, miner status (submitted hash rate, staled hash rate, etc.), and payment status.

https://api.f2pool.com/{currency}/{user0}?multi_account={user1}&multi_account={user2}

Retrieves mining information for multiple accounts of a specific currency. Note that user0 is just a placeholder and does not take effect.

https://api.f2pool.com/{currency}/{user}/{worker_name}

Retrieves the hash rate data of a specific miner under a specific account for the past 24 hours.

https://api.f2pool.com/{currency}/{user}?history={n}

Retrieves the hash rate data of a specific account for the past N days.

N≤60

 

Request Account Details

curl --request GET https://api.f2pool.com/{currency}/{user} \
     --header 'Content-Type: application/json' \
     --header 'F2P-API-SECRET: {token}'

Frequency limit: 15 times/minute

Request Example

Using the API token of account example: 60sai0……zuxuvid to request the BTC details of account example, including account revenue, payment details, hash rate status, etc. 

curl --request GET https://api.f2pool.com/bitcoin/example \
      --header 'Content-Type: application/json' \
      --header 'F2P-API-SECRET: 60sai0……zuxuvid'
